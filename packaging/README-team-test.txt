小暖 · 团队测试版
==================

这台电脑不需要装 Python，也不需要敲命令。

最新版本随时在这里下载（不用 U 盘拷）：
https://github.com/tjusaltedfish/TECHATHON/releases/tag/team-test-latest

第一次使用
1. 把整个压缩包解压到一个短路径，例如 D:\Xiaonuan（不要直接在压缩包里双击运行）。
2. 打开 Windows 设置 → 网络和 Internet → 移动热点：
   - 编辑：热点名和密码与烧录板子时填的一致，网络频带选 2.4GHz；
   - 打开热点。
3. 双击 Xiaonuan.exe。会出现一个黑色窗口（这就是小暖，关掉它就退出），浏览器自动打开设置页。
   - 如果提示“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”（测试版没有数字签名）；
   - 如果弹出“Windows 安全中心”防火墙提示，点“允许访问”。
4. 在设置页：
   ① 粘贴 DeepSeek 密钥，点“保存并测试”；
   ④ 点“一键放行”，在管理员确认里选“是”。
5. 给板子通电（插电脑 USB 或充电宝），上电时不要按压力传感器。
   设置页第 ⑤ 项变绿后，点“打开聊天”，按住传感器说话，松手听小暖回复。

以后使用：打开热点 → 双击 Xiaonuan.exe。

说明
- 聊天记录和密钥保存在 %APPDATA%\Xiaonuan，不在这个文件夹里；把这个文件夹发给别人不会带上你的密钥。
- 语音合成用微软晓伊，需要联网；语音识别在本机完成。
- 出问题时，把黑色窗口里的文字截图发给队友。
