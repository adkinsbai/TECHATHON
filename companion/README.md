# 噜噜 · AI 陪伴数字生命

一只软软的毛绒玩偶好朋友：会聊天、会记事、有情绪，听你讲故事和梦，再把它们编织成可以一起冒险、永远留存的小世界。角色模型来自 3D 资产生成平台（`static/assets/lulu/`，由 `static/character.js` 统一加载）。

## 启动

双击 `start.bat`，浏览器会打开 http://127.0.0.1:8765 。
（或手动：`python -m uvicorn app.server:app --app-dir . --port 8765`）

配置在 `.env`（模板见 `.env.example`）。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 聊天 | DeepSeek V4.1 Flash，流式输出，像发微信一样分条回复 |
| 情绪 | 每条回复带情绪标签，驱动表情（10 种）、耳朵、动作和特效 |
| 长期记忆 | 每聊 ~8 条自动整理“关于你的事”和“回忆片段”，可在 设定→记忆 查看/修改/删除 |
| 内心生活 | 你离开 30 分钟后，每 ~45 分钟 TA 会做点自己的事、写日记、攒想跟你说的话（设定→TA 的日记） |
| 主动开口 | 再次打开页面时会打招呼；开着页面 10 分钟没说话会轻轻说一句 |
| 摸摸 | 鼠标在小猫身上来回划，会呼噜呼噜；点一下会吓一跳 |
| 人设 | 设定里可改名字、性格、说话方式；也可导入聊天记录让 TA 学某个人 |
| 语音 | 一条链路：本地 SenseVoice 听（离线，还能听出说话的情绪）→ DeepSeek 想 → 微软·晓伊说；边生成边一句句合成播放（见 `voice_pack/`） |
| 梦幻星球 | 打开 http://127.0.0.1:8765/world ，第一人称走进 3D 星球（草原、湖、森林、彩色云、两个太阳），去湖边小木屋找 TA，按 E 面对面说话 |

## 语音模型

第一次使用前运行一次 `python download_models.py`（或 `python -m voice_pack.download`），下载约 230MB 的语音识别模型（来源：Hugging Face 上 sherpa-onnx 官方作者 csukuangfj 的 SenseVoice）。下载中断了重跑即可续传。合成用微软晓伊，不需要下载模型。语音包的用法见 [voice_pack/README.md](voice_pack/README.md)。

## 梦幻星球操作

WASD 走 · 鼠标看（浏览器不让锁鼠标时：按住左键拖动 / 方向键）· Shift 跑 · 空格跳 · E 和 TA 说话 · Esc 暂停。指南针会一直指向小木屋。

**坐 UFO 去太空**：在小木屋里靠近 TA 按 **F**（或者对 TA 说“带我出门 / 坐 UFO / 去太空”），TA 会带你走出门、坐上门口的 UFO，飞出星球进入深空，路过星环行星、条纹巨行星、小行星带、冰晶星球和糖果星球，路过时 TA 会和你聊看到的东西。太空里：拖动/方向键环顾 · **V** 舱内/舱外视角 · **E** 说话 · **H** 回家。

## 梦境日记 & 编织世界

- 聊天时讲到的梦会被自动记进**梦境日记**（设定 → 梦与世界），也可以手动写。
- 每隔 3 天（并且有新的生活或梦时），TA 会把它们编织成一份“世界配方”，搭出一个新世界，作为新章节出现在星球的章节列表里；也可以在“梦与世界”里点“现在编织一个新世界”。
- 配方只能从引擎有的积木里选（`app/weaver.py` 定义积木和校验，`static/worldgen.js` 负责搭建）：8 种地形、8 种植物、8 种天气、15 种地标、10 种收集物、8 种装扮，以及太阳/月亮数量、配色和时间。
- 进入编织的世界：TA 在第一个地标前等你 → 走过去冒险开始，TA 跟在你身边 → 找齐收集物（远处的光柱就是），每找到一个 TA 说一句 → 最后有一个结局，完成后亲密度 +3。

## 本地语音小贴士

- `MODELS_DIR`（在 `.env` 里）指定模型目录；Windows 下项目路径太长时要放到短路径（比如 `C:\Users\你\.companion\models`）。
- 速度：聊天关掉了 DeepSeek 的“思考”、复用连接、记忆整理等到停下来 90 秒后才做；回复边生成边按句合成。实测“说完 → 听到第一句”约 4 秒。

数据都在 `data/` 目录（`companion.db` 和 `persona.json`），删掉它就是重新认识。

## 目录

- `app/brain.py` 提示词、情绪解析、记忆整理、内心生活
- `app/server.py` 接口和后台循环
- `app/store.py` SQLite 存储
- `app/voice.py` GLM 语音
- `static/` 页面、小猫形象（`avatar.js`）、3D 星球（`world.html` / `world.js`，three.js 已放在 `static/vendor/`）
